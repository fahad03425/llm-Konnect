  • Dynamic factory router detect_connector() mapping extensions and URI schemes.

Universal CSV & Excel backend/app/connectors/csv_excel.py
  • In-memory encoding detection via chardet.
  • Automated delimiter sniffing (comma, semicolon, tab, pipe).
  • Header row detection heuristic skipping branding metadata lines.
  • Excel multi-sheet discovery (list_sheets) and streaming bytes reading.
Tally Prime & Local DB backend/app/connectors/tally.py
  • parse_tally_xml: Sales, Purchases, Receipts, Payments, and batches.
  • TallyConnector: Live HTTP TDL export client to port 9000 and ODBC DSN collection queries.
  • LocalDBConnector: SQLite and MS Access local databases.
Shopify Admin API backend/app/connectors/shopify.py
  • Multi-resource extraction (orders, products, reviews).
  • Rate-limit resilience (HTTP 429 Retry-After & GraphQL backoff).
  • Order line-item flattening with granular refund and shipping allocation.
  • GraphQL inventory unit cost retrieval (_inventory_costs).
Credential Vault backend/app/connectors/credentials.py
  • AES-GCM encryption of store access tokens at rest.
  • Authenticated associated data (AAD) binding to store subdomains.
API Layer Preview & Sheets backend/app/api/routes.py
  • GET /api/sheets: Discovers Excel workbook sheets for UI selection.
  • POST /api/preview: Generates sample row previews and schema signatures.
